# WhoAreYou

用一张可探索的亲友星图记录关系，查询每个人相对于“我”的关系路径和称呼。数据保存在当前浏览器中，无需登录。

## 开始使用

需要 Node.js 22 或更新版本。在 PowerShell 中运行：

```powershell
npm install
npm run dev
```

打开localhost。安装依赖通常只需首次运行；之后运行 `npm run dev` 即可。

## 星图操作

- 打开即进入星图，没有独立首页。默认进入 3D 星云；设备不支持 WebGL 时会说明原因并切换到 2D。
- 悬浮人物并点击“＋”，选择人物与当前人物的关系。系统依据关系路径生成称呼，保存前可以修改。
- 点击星点，在屏幕下方查看称呼和从“我”开始的完整关系路径。点击路径词可回到那位亲人；点击标题可分别修改姓名和昵称，显示为“张三（老爸）”；未填写姓名时显示昵称或称呼。人物卡片里的删除操作会列出并删除该人物的整条后代分支，“我”不能删除。
- 2D 下拖动空白处平移；W/A/S/D 上下左右移动。点击关系路径或保存资料后仍可继续 WASD 移动；输入文字及打开弹窗时暂停。
- 3D 下鼠标左键拖动原地转头，右键拖动平移；W/A/S/D 按镜头方向前后左右移动，空格上升，左 Shift 下降。触屏单指转头、双指缩放和平移。
- 右下角工具栏切换 2D/3D、缩放、查看全图或回到原点。悬浮或键盘聚焦按钮会显示操作提示。

## 关系检查与管理

- 亲属关系在所属树内以唯一树形路径保存，例如“我 → 爸爸 → 妈妈”。自动称呼用于提供建议；称呼相同不代表是同一个人。
- 添加时如果路径可能对应重复人物或可简化关系，会列出选项供确认。系统不会仅凭树形路径认定人物身份或血缘关系。
- 星图右上角提供“帮助 / 整理 / 变更管理 / 清除”。帮助内含操作说明及清除后的恢复入口。整理会扫描全树并预览建议；清除需确认，且操作前先保存备份。
- 变更管理用图表显示记录，可查看操作前后差异、创建命名存档点并恢复记录的任一侧。恢复会生成新记录，旧记录保留。旧备份和损坏记录会保留在列表中。

## 朋友、同事与搭子

从“我”的添加器选择朋友、同事或搭子并填写姓名，即可建立独立亲属树。例如李四的爸爸显示为“李四的爸爸”，填写其姓名后显示“张三（李四的爸爸）”。路径查询保留“我 → 朋友李四 → 爸爸”。各树只通过社交根与“我”连接，重复检测和整理不会跨树合并人物。删除社交根会一并删除其亲属树，确认前列出范围，删除后可从历史恢复。

为男性关系人物添加丈夫、为女性关系人物添加妻子时，会出现可继续的核对提示。“我”和社交根没有性别标记，不从姓名推断性别。该提示不判断现实血缘或家庭形态。

## 数据与调试

亲友资料和历史版本保存在浏览器 Local Storage 中，仅属于当前浏览器和网址；不同浏览器或端口之间不会自动同步。清除浏览器站点数据会同时删除资料与历史记录。

- 修改 `src/` 或 `index.html` 后刷新浏览器；当前开发服务器不提供热更新。
- 按 F12 打开开发者工具：Console 查看错误，Sources 设置断点，Elements 临时检查样式。
- 旧版资料读取时兼容新版姓名/昵称结构，原 `alias` 作为昵称保留。首次写入新版前，将原始资料保存在 `whoareyou.family.v1.before-v2`；“变更管理”中可查看“升级前资料”。旧历史原文不被改写。
- Application → Local Storage 可查看 `whoareyou.family.v1` 资料及 `whoareyou.snapshot.v1.*` 历史记录。
- 终端按 Ctrl+C 停止开发服务器。

## 检查、测试与构建

```powershell
npm run check
npm test
npm run build
```

测试包含四级以内 11,110 种关系组合的遍历，完整测试可能需要一分多钟。页面逻辑使用 happy-dom 测试；视角移动使用独立数学测试。它们不能替代真实浏览器中的 WebGL、触屏和视觉检查。

构建产物输出到 `dist/`，包含本地称呼引擎、Three.js 及其许可证文件，不依赖 CDN。部署时将 `dist/` 作为站点根目录，并确保 `/src/` 与 `/vendor/` 路径可访问。
